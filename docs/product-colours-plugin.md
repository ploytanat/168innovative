# ติดตั้งตัวเลือกสีแบบกรอกฟอร์ม

วิธีนี้ใช้แทนไฟล์ ACF JSON ที่เตรียมก่อนหน้า ไม่ต้องซื้อ Pro และไม่ต้องสร้าง Product Group

1. WordPress → ปลั๊กอิน → เพิ่มปลั๊กอินใหม่ → อัปโหลดปลั๊กอิน
2. เลือก `docs/168-product-colours.zip` แล้วติดตั้งและเปิดใช้งาน
3. เปิด Product Variants → แก้ไขสินค้ารุ่นที่ต้องการ
4. ที่กล่อง “สีและรูปสินค้า / Colour images” กดเพิ่มสี ใส่ชื่อไทย/อังกฤษ เลือกรูป และใส่รหัสสีถ้าต้องการ
5. กดอัปเดตสินค้า รอแคชเว็บไซต์ประมาณ 60 วินาที แล้วเปิดหน้าสินค้า

ต้องใช้ Next.js เวอร์ชันที่แก้ใน workspace นี้ด้วย โค้ดนี้ยังไม่ได้ deploy ขึ้นเว็บไซต์จริง

ปุ่มรูปหลักยังอยู่เหมือนเดิม ตัวเลือกสีเปลี่ยนทั้งรูปบนหน้าและรูปขยาย สินค้าไม่มีสีจะเหมือนเดิม ปลั๊กอินเก็บข้อมูลแยกใน post meta `_168_product_colours` และเปิดอ่านผ่าน REST `colour_images` ไม่มีราคา สต็อก หรือการบันทึกสีลงใบสอบถาม/shortlist

ตรวจ TypeScript และ JavaScript syntax แล้ว ยังไม่ได้รันปลั๊กอินใน WordPress จริง และเครื่องนี้ไม่มี PHP สำหรับตรวจ syntax ด้วย php -l
