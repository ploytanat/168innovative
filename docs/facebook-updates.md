# อัปเดตจาก 168 — เลือกโพสต์ Facebook มาแสดงบนเว็บ

ส่วนนี้อยู่บนหน้าแรก ใต้รายการสินค้า แสดงได้สูงสุด 3 โพสต์ต่อภาษา โดยใช้ WordPress เดิม ไม่ต้องติดตั้งปลั๊กอินหรือสร้าง Meta App และไม่ดึงโพสต์ Facebook อัตโนมัติ

## เพิ่มโพสต์

1. เข้า WordPress → **เรื่อง / Posts → เพิ่มเรื่องใหม่** (ไม่ใช่เมนู Article ที่ใช้สำหรับบทความ)
2. ใส่ชื่อสั้น ๆ ที่ต้องการให้แสดงบนเว็บ
3. ใส่รูปใน **รูปภาพประจำเรื่อง / Featured image** ใช้รูปที่บริษัทมีสิทธิ์นำมาแสดง
4. ใส่ข้อความสรุปใน **Excerpt / ข้อความเกริ่นนำ** ระบบแสดงไม่เกิน 220 ตัวอักษร
5. ในเนื้อหา เพิ่มบล็อก Paragraph แล้ววางลิงก์โพสต์ต้นฉบับ เช่น `https://www.facebook.com/.../posts/...` เป็นข้อความหรือลิงก์ธรรมดา ไม่ต้องใช้บล็อก Embed
6. เลือกหมวดเดียวตามภาษาของเนื้อหา:
   - **Facebook updates (Thai)** — slug `facebook-updates-th`, category ID 46
   - **Facebook updates (English)** — slug `facebook-updates-en`, category ID 47
7. กดเผยแพร่ หลังแคชเริ่มหมดอายุประมาณ 60 วินาที การเข้าหน้าถัดไปจะเริ่มดึงข้อมูลใหม่ อาจต้องรอการรีเฟรชแคชเสร็จอีกเล็กน้อย

หากต้องการสองภาษา ให้สร้างสองเรื่องพร้อมคำแปลและเลือกหมวดให้ตรงภาษา ไม่ต้องสร้างโพสต์ซ้ำใน Facebook

## การแสดงผล

- พิจารณา 12 เรื่องที่เผยแพร่ล่าสุดในหมวด แล้วเลือก 3 เรื่องที่มีชื่อ รูปปก และลิงก์ Facebook ครบ
- เรียงตามวันเผยแพร่ใน WordPress; ไม่มีการอ้างว่าวันนั้นคือวันโพสต์บน Facebook
- เรื่องที่ซ้ำลิงก์ เรื่องแบบร่าง เรื่องที่ไม่มีรูป หรือ URL ไม่ถูกต้องจะไม่แสดง
- รูปดึงจาก WordPress โดยเลือกขนาด medium_large เมื่อมี ไม่โหลด Facebook SDK, iframe หรือสคริปต์ติดตามของ Facebook
- กดการ์ดเพื่อเปิดโพสต์ต้นฉบับในแท็บใหม่; ปุ่มดูเพจใช้ URL จากข้อมูลบริษัทที่มีอยู่แล้ว
- ถ้าไม่มีเรื่องที่พร้อมแสดง หรือ CMS ขัดข้อง จะมีแถบลิงก์ไปยังเพจจริงแทน ไม่มีโพสต์จำลอง
- เปลี่ยนเรื่องเป็นแบบร่าง/ถังขยะเพื่อนำออกจากหน้าเว็บ แล้วรอแคชเช่นเดียวกับการเพิ่ม
- สามารถล้างแคชผ่าน endpoint เดิม `/lib/api/revalidate` ด้วย tag `facebook-updates` และ secret ที่ตั้งไว้ โดยไม่ใส่ secret ลงในหน้าเว็บ

## สถานะที่เตรียมไว้

สร้างหมวด 46 และ 47 ใน WordPress จริงเรียบร้อยแล้ว ยังไม่ได้เพิ่มหรือเผยแพร่โพสต์แทนผู้ใช้ ต้องเลือกโพสต์ต้นฉบับและรูปที่จะนำมาใช้ก่อน

## การตรวจสอบ

TypeScript, application ESLint และชุดทดสอบข้อมูล/URL ผ่าน ตรวจหน้าแรกไทย–อังกฤษผ่าน HTTP และพบลิงก์ไปยังเพจจริง ไม่พบ Facebook SDK ใน HTML ผลทดสอบครอบคลุมโดเมนปลอม, URL ไม่ปลอดภัย, โพสต์ไม่ครบ, รูปนอก CMS, ลิงก์ซ้ำ และการเลือกขนาดรูป

ไม่มีเบราว์เซอร์เชื่อมต่อสำหรับตรวจภาพจริง การแสดงการ์ดจากโพสต์จริงยังต้องตรวจหลังเพิ่มโพสต์ชุดแรก; ไม่ได้เผยแพร่โพสต์ปลอมเพื่อทดสอบ
